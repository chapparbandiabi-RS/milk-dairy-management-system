\# Milk Dairy Management System



A Windows desktop application designed to simplify daily milk dairy management, customer records, attendance, milk collection, billing, and payment tracking.



\## Features



\- Customer management

\- Add, edit, and manage customer details

\- Store customer phone number and address

\- Set milk price per litre

\- Daily customer attendance tracking

\- Record daily milk quantity

\- Morning and evening milk entry

\- Automatic total milk calculation

\- Monthly bill management

\- Payment tracking

\- Customer payment reminders

\- SQLite database for storing application data

\- Simple and user-friendly desktop interface



\## Technologies Used



\- Electron.js

\- Node.js

\- JavaScript

\- HTML5

\- CSS3

\- SQLite

\- Git \& GitHub



\## Database



The application uses SQLite to store dairy information locally.



Main data includes:



\- Customers

\- Attendance

\- Milk entries

\- Bills

\- Payments
